# Layout spec

Status: current

## Job

Home page. Job: a builder understands what ShipRight does in 5 seconds and installs it. Primary action: Install ShipRight.

## Zones

Top to bottom. Each act is a new composition (W4).

| # | Act | Tone | Composition | Pain |
| --- | --- | --- | --- | --- |
| 1 | Run | Dark | Left: headline, one line, Install, Watch the run. Right: replay window with 5 beats. Phone: stacked, window under the buttons. | S01, S08 |
| 2 | Doors | Paper | Two equal doors side by side: "I have an idea" and "I already built something". Each shows the command and the stages it runs. | S02 |
| 3 | Folder | Paper, ink panel | Left: real file tree from the c3 run. Right: reader pane with a short real excerpt. | S02 |
| 4 | Work | Paper | Tabs over a full-width drag slider. Four pairs. Caption says what was compared. | S07, S04 |
| 5 | Stages | Dark | 11 stage tiles in a grid, number, name, the file it writes. | S06 |
| 6 | Proof | Paper | Three pairs, two columns each, one honest line per pair. Then what 1.3 changed. Status said once. | S05, S03 |
| 7 | Install | Ink band | Centered panel, tabs, Copy. | K4 |
| 8 | FAQ | Paper | Hover-invert rows, one open. | S09 |
| 9 | Footer | Dark | One row. | |

Grid: max width 1200px, 32px side gutters at 1280, 16px at 390. Gaps on 8, 16, 24, 32, 48, 64.

## Hero

The replay window. Beats: 1 You ask. 2 It asks 3 cards. 3 You reply. 4 It writes the files. 5 It shows the screen, and what only you can confirm. Label: "Replay of a real run. Case c3, Sonnet with ShipRight 1.2. Text shortened."
