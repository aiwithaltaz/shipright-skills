Stage 7 for the site rebuild. The look stays (K1). Options differ in story, not color.

## Options

| | A. Watch a real run | B. Open the folder | C. Before and after first |
| --- | --- | --- | --- |
| Story | The first screen replays a real ShipRight run: prompt, decision cards, "you decide", files written, the screen it built. | The first screen is the folder a run writes. Tap a file to read a real excerpt. | The first screen is a drag slider of one before and after. |
| Device | Replay window with five tappable beats, plays once in view | File tree plus reader pane | Full-width slider |
| Proves | It asks before it builds, it writes files, it builds a screen | The output is real and readable | The output got better |
| Weak spot | Needs a real run to replay | Files are less exciting than screens | Says nothing about process or install |
| Refuses | Fake 3D, invented chat, a score | Fake files | A winner claim |

## Pick

**A, with B as the third act.** Proposed, awaiting owner approval.

Why: the product is a skill, so the product on stage (W2) is a run. The c3 run (Sonnet with ShipRight 1.2) exists on disk with its questions, its scripted owner reply, its reply, its files and its screen. Nothing needs to be invented. B becomes the folder act. C becomes the work act with all four before/after pairs.

## Deviation from stage 8

Stage 8 says a premium site copies `scroll-story`, `product-3d` and `page-transition`. This site keeps `page-transition` and does not use `product-3d`: ShipRight has no physical object, and the 1.2 audit called the paper-box 3D fake. The run window is plain HTML, CSS and a small script. Logged as D5.
