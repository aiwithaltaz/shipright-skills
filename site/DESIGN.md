# Site design, 1.3.1 run rebuild

Paper and ink, one accent: sealing wax `#9d3419` (`data-accent-source` is "sealing wax on the record"). Fraunces for titles, Inter for text, monospace only inside code. All self-hosted.

The first screen is the product working: a replay window of the real c3 run, with the screen that run built behind it. On a phone and below 1101px the screen sits above the window.

Spacing: 4, 8, 16, 24, 32, 40, 48, 64. Radii: 12 buttons, 16 tabs and pills, 24 cards and panels. Focus: 1px outline, 2px offset.

Acts do not repeat a layout: dark split hero, centered doors, tree and reader, full-width slider, dark stage grid, centered proof, ink install band, FAQ list, dark footer.

Motion: line masks on titles, 24px fade-up, 70ms stagger, cubic-bezier(.22, 1, .36, 1). The replay plays once in view and stops on any tap. Reduced motion shows every step in order and runs nothing. Everything reads with no JavaScript.

Honest limits: the replay is a 1.2 run, labeled. 1.3 eval scores are pending. Taste is Not verified.
