## How the goals hold up

The goals used here: ask only 3 to 5 questions, offer examples or Let me decide, do not dump the whole product before it is settled, include UX critique, and drive the PRD, technical architecture, security and access, frontend spec, and feature tickets.

| Goal | Where it stands in 0.6.1-draft |
| --- | --- |
| 3 to 5 questions | Written in shared intake. Clear tasks ask zero. A vague idea aims for three. |
| Examples or Let me decide | The card rules are explicit. The only worked card is about clearing a draft. |
| Do not dump before the frame is settled | Doc files wait for a frame. The frame itself may still be drafted in the first reply. |
| UX critique | Present, with severity, flow rules, and evidence limits. |
| Five docs | Owned in the output folder. Frontend spec and DESIGN.md sit with ui-ux-design. |

Taste Skill is a visual point of view. UX UI Design Pro is a large pattern catalog. This pack should not copy either one. It already refuses invented brands. It does not yet show the screen that mistake produces.

## Ranked weak spots

1. **The first reply can still design the product.** product-design says to keep going on independent work, then derive objects and screen jobs. A vague "build it" becomes a system, a journey, and extra features in the same turn as the questions.
2. **Generic screens are described, not shown.** Anti-slop rules ban unsupported widgets. They never name the usual booking homepage or the usual four-card dashboard, so those layouts still feel allowed.
3. **Critique has no worked finding.** The fields are listed. There is no example to copy, so a review can slide into a restyle or a new chart.
4. **Ship check dumps a table when nothing exists to check.** Items correctly start as Not verified. The skill does not say to ask for a URL or a build and stop.
5. **README setup is thin for ChatGPT.** Claude Code, Cursor, and Codex are named. ChatGPT is not. No screen shows what the rules change.

Format across the four skills is mostly consistent: intake, a short sequence, then a numbered gate. ship-check does not use the flow-rule link, on purpose, because launch evidence is its own gate.
