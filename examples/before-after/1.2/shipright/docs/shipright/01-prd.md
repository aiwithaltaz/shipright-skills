# ShipRight public website product brief
Phase: specification and interactive direction selection. No build until owner selection.

## Visitor and job
Proposed (delegated): developers and founders evaluating an AI skill for a product or public website. The visitor should understand what ShipRight changes about a build, identify the relevant mode, and leave with the real installation command. Observable checks: the opening identifies ShipRight as one skill; all five modes are discoverable; the exact command can be copied and the repository reached.

## Scope and exclusions
One public page with a six-act story, real skill-output evidence, five mode explanations, install-copy interaction and repository links. No accounts, checkout, prices, customers, ratings, legal text, contact form, fabricated performance claims, sound, supplied models or invented images.

## Product hero
The actual build pack is the hero: a readable document fragment representing the real ShipRight contract and output filenames, explicitly labeled “Build-pack output structure.” It appears in the first HTML screen. It is a product representation, not a fake dashboard. Clean paper-like surfaces, flat readable light, approximately half the desktop opening, stacked under the heading on phone. No decorative 3D proxy.

## Six-act plan
1. Opening: meet one skill and the real output structure; learn “Context before generate. Product before pixels.”
2. Second act: understand that context precedes visual generation; the brief and decision move forward while the explanation stays readable.
3. Third act: learn one skill has five modes; rearrange the output into a mode index with a materially different composition.
4. Detail: inspect real artifacts and the required build → preview → build → critique → ship-check sequence; annotated evidence remains still enough to read.
5. Close: install using `npx skills add aiwithaltaz/shipright-skills`; actual repository link answers where it comes from.
6. Footer: ShipRight name, real repository, return to opening. Omit unknown legal/contact destinations.

## Assets and sources
No supplied visual, sound or model assets. Product facts: user request and local skills/shipright/SKILL.md plus build-pack/MODE.md and pack-contract.md. Actual output filenames may be displayed as evidence of the documented contract. No claim of customer results. Procedural typography and document illustration do not claim to be a running app.
