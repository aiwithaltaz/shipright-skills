# Three story directions: owner choice required
Same hero in each: actual ShipRight build-pack output structure. Same facts: one skill; five named modes; product promise; exact install command; actual repository. These are story options, not palette swaps. Inspiration patterns are editorial specimen, production choreography and technical field guide; no external layout or asset is copied.

## A. The Product Manuscript
Story device: inspect an unusually beautiful working document. A broad ivory stage meets an oversized serif “Product before pixels.” with the actual output sheet interrupting its baseline. The page reads like a designed book whose annotations become the navigation.
Techniques: object in front of text, pinned scroll scene, block wipe, hover invert.
Type: Georgia display, Arial body, monospace annotations. Palette: paper #f1efe8, ink #232622, vermilion #d8492c.
Acts: (1) meet output sheet against giant promise; (2) pinned sheet reveals context/decision margin notes; (3) five modes form a typographic chapter index, not cards; (4) a spread annotates PRD, architecture, design, frontend and ticket artifacts; (5) a single oversized install line closes the manuscript; (6) colophon links repository/top.
Moves: sheet alignment and margin markers; readable text remains DOM. Refuses: dashboards, decorative geometry, terminal theater, invented results.

## B. The Decision Assembly
Story device: follow a raw brief becoming an explicit build pack. An architectural grid shows the same real document sections initially separated, then aligned by the story. More kinetic, technical and precise.
Techniques: pinned scroll scene, block wipe, text scramble, hover invert.
Type: Arial bold display, Arial body, monospace labels. Palette: near-black #171a19, chalk #eceee8, acid lime #c6ea69.
Acts: (1) brief + actual artifact stack; (2) context resolves into a decision ledger before any generation; (3) five modes branch from one skill as a wide indexed diagram; (4) artifacts align into the documented full workflow; (5) exact install command crosses a clear horizontal threshold; (6) compact source ledger/repository/top.
Moves: grid pieces align, one small nonessential label scrambles; facts stay visible. Refuses: fake progress, futuristic 3D scenery, gate, model claims and glowing feature cards.

## C. The Field Guide
Story device: choose a job, then trace the corresponding real skill mode. This is a distinctive oversized editorial reference, emphasizing legibility and navigation over spectacle.
Techniques: object in front of text, block wipe, hover invert.
Type: Georgia italic display contrasted with Arial black index numerals and monospace artifact labels. Palette: cobalt #193dcc, warm white #f6f4ed, pale ink #c7d3ff. Single cobalt accent against paper after opening.
Acts: (1) cobalt cover with real output page in hand and the product promise; (2) a full-width context-before-generation editorial cut; (3) five giant numbered mode rows teach which job each mode serves; (4) actual output specimen occupies a detailed annotated full-width plate; (5) quiet paper install spread with precise command; (6) blue colophon with source/top.
Moves: a document crosses heading type, two large section wipes; no pin/inertia required on phone. Refuses: feature-card grid, fake app screenshot, decorative particles, invented authority and scroll gates.

Recommendation: A. It makes the actual product output the premium object and makes the promise tactile without inventing software UI. This remains Proposed; owner chooses A, B or C before build.
