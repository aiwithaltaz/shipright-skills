# IVC 2026 desk frames

These pictures record Altaz's Figma redesign of the IVC 2026 registration desk. They are styled reconstructions of the attached frames, cropped to the desk. The original PNG bytes were not in the workspace, so these are not pixel crops of those files. Figma chrome is left out.

The scale is **pending from Altaz**. Type, spacing, color, radius and elevation in the HTML are illustration sizes only. Do not treat them as measured tokens.

## Person details

[Before](before-person-details.png) is the earlier form: small fields, no section headings, and a button named Save and next person.

[After](after-person-details.png) groups fields under small headings (Name, Emergency contact, Other details), uses larger fields, puts status pills next to the name, and has one named next button.

The attached after frame labeled the first field Last Name twice. That bug is not copied. The first field here is First name.

## Search results

[Before](before-search-results.png) puts status on its own row and nests a guardian box inside the result card.

[After](after-search-results.png) puts status pills next to the name, uses one meta line, and drops the extra nested box.

Contact numbers from the frames are not repeated. Sample text says On file or name@example.com. Names match the frames so the lesson stays recognizable. They are the fictional desk samples, not a claim about real people.

This folder does not replace the historical prototype or its evidence. It does not approve a new token scale.
