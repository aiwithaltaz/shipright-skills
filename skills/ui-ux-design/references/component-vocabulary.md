# Component vocabulary

Load only when a spec names controls. Do not load it for a one-label correction.
Names and aliases are the usual names for these controls. Purposes here are ours. Credit Component Gallery by Iain Bean. Do not copy its definitions, guidance, code or screenshots. Links point at the Gallery page for that name.

Every control in a spec maps to a canonical name or an existing app component. If a control cannot be named, justify it or remove it.
Handoff names the canonical name plus the library name (for example Modal = shadcn Dialog).
