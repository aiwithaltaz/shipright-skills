# Content and media references
Readable type first: 60 to 75 characters a line, clear hierarchy, little chrome.

- **Stripe Press (press.stripe.com):** book-like type and pacing.
- **The Verge (theverge.com):** bold editorial grid and color.
- **Stripe Docs / Vercel Docs:** side nav, code blocks, search.
- **Medium (medium.com):** quiet reading view.
- **Substack (substack.com):** simple post and subscribe flow.
