# Stage 4: Scope and pages

Keep the core value. Cut the rest. List every page. Open [scope.md](../templates/scope.md) and [system-pages.md](../patterns/system-pages.md).
Required headings in scope.md: Core loop, Value floor, Flows, Page inventory.

## Steps

1. Write the core loop from the chosen concept. What the user does every day, in order.
2. Write the value floor: "The first release must include the one thing that makes the product worth using." A LinkedIn assistant without drafting help is a notes app. Cut anything that does not serve that floor to Later.
3. Name flows after real moments in the user's week ("Monday planning", "Rain day", "Friday invoicing"). Each flow: trigger, steps, success, failure, exit (F1).
4. Page inventory. Mark each surface Needed, Not needed, or Later, with a reason. Cover public pages, auth, onboarding, the app core, account, empty/loading/error/offline, 404, 500, legal (placeholder, "needs legal review"), email, and meta (title, description, favicon). Do not invent legal text.
5. For each Needed page: job, primary action, states, phone layout, and real copy. Copy comes from Supplied facts or is labeled Sample.

## Existing app

Scope only the Now pains. Every page you add names its pain ID.

## Record

Update CONTEXT.md phase and locks. Add scope cuts to DECISIONS.md.

## Gate

Value floor is kept. Every page is Needed, Not needed, or Later with a reason. Record updated.
