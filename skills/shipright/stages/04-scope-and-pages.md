# Step 04: Tech stack

**Deal first:** run `node <skill>/scripts/deal.mjs --stage 04 --tags <project tags>` and apply the cards it prints. Do not open `library/` yourself.

Open [04-stack.md](../templates/04-stack.md).
Required headings in 04-stack.md: Constraints, Choices, Revisit.

Choose the smallest stack that meets the requirement IDs. The existing project or named tool wins. For each necessary layer: choice, reason, alternative, cost assumption and switch condition. Say Not needed when there is no backend or database.

Choose a component system and one chart implementation path when analytics is required. Check its chart types, formatters, keyboard alternatives and responsive behavior. A UI kit is not access control or proof of visual quality.

CSS handles simple transitions. Add coordinated motion, smooth scrolling or 3D only for an identified job. Ordinary CRM screens need no GSAP, Lenis or Three.js by default. Website stack decisions remain in stage 5. Copy the chosen stack once into ARCHITECTURE.md.

## Record

Reuse the router's decision summary. Update only changed project-record fields.

## Gate

The template answers the decisions above with evidence or explicit unknowns. No new features or facts were invented. Record updated.
