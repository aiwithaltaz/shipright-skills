# Layout moves

Run these before any color or type. One screen at a time.

## 1. Reorder by priority

Order sections by what the user needs first. Re-check when importance changes.
Why: a FAQ above the form makes the task late.
Good: title, deadline, and form first. FAQ below.
Bad: marketing copy above the only action.
Check: the first zone is the primary action's home.

## 2. Group related things

Group by meaning. A secondary fact sits beside its main fact.
Why: a status far from the name gets missed.
Good: status next to the name. Details in their own section.
Bad: the same fact repeated in a header and a card.
Check: each fact has one home.

## 3. Move controls to the work

The fix sits where the problem shows.
Why: a button in a distant toolbar is a second search.
Good: the next action on the result card.
Bad: select a row, then find the action in another panel.
Check: the fixing action is in the same zone as the item.

## 4. Align to the grid

Edges line up across columns. Use the spacing scale.
Why: ragged edges look unfinished and waste a scan.
Good: a review card starts level with the form card.
Bad: a card indented by an off-scale gap.
Check: widths at 390 and 1280 are written, and gaps are on the scale.

## 5. Make the key thing bigger

One hero element gets size and contrast. Demote the rest.
Why: if everything is loud, nothing is.
Good: one map, one product, or one situation line is clearly largest.
Bad: four equal cards and no hero.
Check: the layout spec names one hero.

## 6. Simplify the interaction

Fewer steps. Show the target. Make the basic action automatic.
Why: extra steps hide the job.
Good: one control does the obvious move.
Bad: select, add, open a card, then start.
Check: the primary task's step count is written, and a step was cut or the reason it stays is written.

## 7. Make state obvious

State is visible and looks like what it is.
Why: a color alone is not a state.
Good: a finished step has a check and a word. A disabled value looks disabled.
Bad: the only sign of state is a thick bar on the left.
Check: each state in the spec has a visible treatment, not color alone.

## Removal test

After the seven moves, drop anything that repeats, has no job right now, is unconfirmed, is a later phase, is the wrong audience, or fights the main action.
