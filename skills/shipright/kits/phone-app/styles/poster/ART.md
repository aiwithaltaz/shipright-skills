# Poster: Swiss sport poster
For: energetic, competitive, younger products (fitness, running, streaks, challenges, money goals).
Feel: stadium scoreboard, track poster. Loud and exact.
- Type: Archivo Black/900 condensed, uppercase, huge (64 px title). Space Mono for every number.
- Color: near-black, off-white, ONE acid lime for done and actions, orange only for hot streaks.
- Shape: square corners everywhere. No shadows except hard offset on the add button. Thick left bar marks done rows.
- Detail: the score block (2/5) is a solid lime square; pixel-square history grid.
- Never: soft pastels, round pills, blur, thin grey text on black.
