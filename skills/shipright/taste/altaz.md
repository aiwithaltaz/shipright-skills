# Altaz taste profile

Opt-in. Load this only when the owner is Altaz or the project says to use it.
It does not set scope, prices, legal text, or access. An existing approved system wins.

The older note at the pack root keeps the historical spacing line. This file is the one to follow for new work. 12px is a kicker size, not a gap.

## Decisions

- Clarity over cleverness. The main task first. Background info goes lower.
- Group by meaning. Put a secondary fact beside its main fact.
- Honest. No fake counters. "Coming soon" beats invented content.
- Public pages are premium and touchable. One live moment above the fold works on tap, not only hover.
- Same labels, same status meanings, same buttons.
- Phone first on public pages.
- On a new idea: who it is for, how it makes money, how it scales, and the next step.

## Feedback

- Crops are the spec. A full screenshot is context only.
- What he likes is locked.
- If he names the wrong cause, say so once, then do what he chooses.
- Decide with 2 to 4 options, recommended first, and a short preview.
- Ship only when he says to push. Then check the live page.

## Numbers, when no system exists

- Gaps: 4, 8, 16, 24, 32, 40, 48, 64. No 2, 6, 10, or 12 gaps.
- Display line-height 1.2. Kickers 12px, uppercase, 0.14em tracking.
- Icons: Lucide, 1.5 stroke, text color.
- Radii: 12 fields and buttons, 16 tabs and notices, 24 cards.
- Focus: 1px. The field border turns brand. Buttons get a 1px outline and a 2px offset.
- Selection: a full even border. No thick accent bar. No dot on the active nav item.
- Back starts with a left arrow. Next names the destination.
- Errors on blur or submit, never while typing. An error does not push its neighbor.
- Motion: line masks, 24px fade-up, 70ms stagger, cubic-bezier(.22, 1, .36, 1). Visible with no JavaScript. Off under reduced motion. Scope every class.

## Removal test

In order. One bad answer and it goes: does it repeat, does it have a job right now, is it real, is it this phase, is it this audience, does it fight the main action.
