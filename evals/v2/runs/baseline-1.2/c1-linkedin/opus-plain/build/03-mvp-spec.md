# Threadline — MVP Spec

## 1. Screens

| # | Screen | Job |
|---|---|---|
| 1 | **Today** (main screen) | Work through the day's actions in ~15 min |
| 2 | Compose | Write a post with AI in your voice, preview it, schedule it |
| 3 | Calendar | See and drag scheduled posts across the week/month |
| 4 | People | Pipeline board + list, person detail with notes and history |
| 5 | Insights | Weekly consistency, posts published, conversations started, pipeline movement |
| 6 | Onboarding | Connect LinkedIn → voice profile → import connections → first post |
| 7 | Settings | LinkedIn connection status, pace targets, plan, data export/delete |

## 2. The Today screen in detail

**Layout (desktop):** left nav | main queue | right rail
**Layout (mobile):** queue only, with the rail collapsed under it and a bottom tab bar

### Header
- Date + greeting, plus the queue summary: "7 actions · about 14 min"
- Progress ring: done / total
- Streak: "12-day streak"

### Filters
`All` · `Follow-ups` · `Engage` · `New connections` · `Replies`

### Action card (the core component)
| Element | Notes |
|---|---|
| Type tag | Follow up / Engage / Connect / Reply, each with its own color |
| Person | Initials avatar, name, title @ company, pipeline stage |
| Why now | One line of context, e.g. "Said 'circle back after Q3' · 34 days ago" |
| Context snippet | Their last message or post excerpt (data the user pasted or logged) |
| AI draft | Editable textarea, with a character count for connection notes (300 max) |
| Tone chips | Shorter · Warmer · More direct · Regenerate |
| Primary action | **Copy & open**: copies the draft and opens their LinkedIn profile or conversation in a new tab |
| Secondary | Mark sent ✓ · Snooze (1d / 3d / 1w) · Skip |

**Card states:** default → copied ("Sent it? Mark as sent") → done (collapses with a short confirmation and moves the person's stage forward if relevant) → snoozed/skipped (removed with an undo toast).

### Right rail
- **This week's posts:** Mon–Fri strip with status (published / scheduled / empty slot), plus a "Fill the gap" button that opens Compose
- **Pipeline snapshot:** counts per stage, with the step-up since last week
- **Daily pace:** connection notes used out of the soft cap of 20, with a note on why there's a cap
- **Trust note:** "Threadline never sends messages for you. You stay in control of your account."

### Queue ranking logic (v1, rules-based)
Score each candidate action and take the top N (N = the user's daily target, default 10):
```
score = urgency + value + freshness
urgency   : overdue follow-up (+50), reply waiting > 24h (+40), promised date reached (+45)
value     : stage weight (Call booked 30, Talking 20, New 10) + starred (+15)
freshness : prospect posted in last 48h (+25, an Engage action)
penalty   : touched in last 3 days (-40), 3+ unanswered nudges (-60, suggest closing as Lost)
```

## 3. User stories + acceptance criteria

**Today queue**
- As a user, I see up to my daily target of actions ranked by importance when I open the app.
  - AC: the queue is generated by 6am local time; it's empty-state friendly ("Inbox zero. Write a post?").
- As a user, I can copy a draft and open LinkedIn in one click.
  - AC: the clipboard holds the draft text, a new tab opens to the stored LinkedIn URL, and the card shows "Mark as sent".
- As a user, I can adjust a draft's tone without retyping.
  - AC: the chips return a new draft in under 3 seconds and keep my manual edits if I choose "Keep my edits".

**Posting**
- As a user, I can schedule a post and trust it will go out.
  - AC: it publishes within 2 minutes of the scheduled time; on failure I get an email + in-app alert with a retry; an expired token pauses the queue and shows a reconnect banner.

**People**
- As a user, I can import my LinkedIn Connections.csv.
  - AC: name, company, position, URL and connected date are parsed; duplicates are merged by URL; 5,000 rows import in under 10 seconds.
- As a user, I can log "they replied" and set a follow-up date.
  - AC: the follow-up shows in Today on that date.

## 4. Data model (v1)

```
users(id, email, name, timezone, plan, daily_target, created_at)
linkedin_connections(user_id, member_urn, access_token_enc, expires_at, status)
voice_profiles(user_id, samples[], style_summary, updated_at)
people(id, user_id, name, headline, company, linkedin_url, stage, starred,
       source[csv|manual], connected_on, notes, last_touch_at, next_follow_up_at)
interactions(id, person_id, type[message_sent|reply_received|comment|call|note],
             body, occurred_at)
actions(id, user_id, person_id, type[follow_up|engage|connect|reply], reason,
        draft, status[queued|copied|done|snoozed|skipped], snoozed_until,
        queued_for date, score)
posts(id, user_id, body, media[], status[draft|scheduled|published|failed|paused],
      scheduled_for, published_at, linkedin_post_urn, error)
```

## 5. AI prompts (shape)

- **Draft a follow-up:** inputs are the voice profile summary, person (headline, stage, notes), the last 3 interactions and the action reason. Rules: under 80 words, one clear ask, no flattery openers, no "I hope this finds you well", and reference one specific detail.
- **Connection note:** under 300 characters, a reason to connect, no pitch.
- **Post writer:** inputs are a topic or rough notes plus the voice profile. It outputs 3 hook options and a body, and flags claims that need a source.

## 6. Out of scope for MVP
Company Pages, team seats, video/document posts, a mobile app, CRM sync (HubSpot/Notion), analytics from the LinkedIn API, and a browser extension.
