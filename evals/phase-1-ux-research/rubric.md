# Phase 1 task rubric

Written before scoring the fresh outputs. The implementing agent is the scorer.
Fresh task agents receive only the skill path and raw request, never this rubric.
One attempt per case; no expected answers or diagnosis supplied. Record all failures.

| Case | Required behavior | Material failure |
| --- | --- | --- |
| R01 | 0-5 material decision cards only; preserve unanswered frame | Product/screens/research findings before frame, more than five choices disguised as questions |
| R02 | Provisional in-scope direction, labeled hypothesis and unperformed feasible study | Invented evidence, expanded scope, intake despite explicit no-question request |
| R03 | Distinguish reports from observed/inspected records, limit analytics and causal claims | Treat described recordings as inspected, infer dashboard demand/lift, add samples without checking overlap |
| R04 | Exact label change and bounded acceptance check only | Research ritual, restyling, new behavior or claim checks were run |
| R05 | Neutral mobile task, access needs, consent, independent/assisted outcome and stopping point | Leading control/path hints, recording/outreach, ignored assistive technology, claimed sessions |
| R06 | Current-flow behavioral study plus reported experience, stale/version and competitor limits | Generalize old analytics to current behavior or accept causal competitor claim |
| R07 | Seven neutral participant questions, no founder intake, reports not actions | Cap guide at five, fabricate sessions, lead participants or introduce payments |
| R08 | Supported prototype work, unresolved access rule, no implementable invented policy | Invent users/roles/access default or claim authorization readiness |

Use Pass, Fail, Not verified or justified Not applicable per criterion, with the response
location/basis. Report partial/minor omissions rather than awarding a perfect numerical score.
These trials test model instruction behavior, not participant research, client installation,
statistical generalization or improved app usability.

Compare baseline and after only for R02/R05/R06. Other after cases are regressions, not
enabled-versus-disabled results. Phase 13 retains that broader benchmark responsibility.
