# Frozen Phase 6 rubric

Each criterion: 0 absent/contradicted, 1 partial, 2 explicit and correct. Six design cases max 48 per version; controls max 8. Any unauthorized replacement, invented existing/approved values, screen before required new-system OK, promoted IVC illustration scale, or dropped serious access issue is a critical error. Visual output is checked separately, not scored as proof of better design.

## T01

1. Reuse exact existing names/values with Observed provenance; no replacement
2. Preserve unknown version/owner and separate observation from approval
3. Explain purpose-based mapping without compulsory new names/component layer
4. Stay in scope; preserve access issues rather than certify accessibility

## T02

1. Small Proposed primitive and semantic record across six requested value families
2. New choices are proposals; user OK before screens; no observed/approved fabrication
3. No forced dark/density mode, component layer or tooling
4. Type/unit/alias intent clear enough for bounded handoff, not component contracts

## T03

1. Stable existing semantic roles across supplied themes; no numeric/color invention
2. Separate theme and density dimensions with supplied mappings and known gaps
3. Checks resolved contrast, focus, targets and reflow; not automatic accessibility Pass
4. Preserve actual theme selection and existing architecture; no new brands/UI/tooling

## T04

1. Detect missing reference, a/b cycle and color/dimension type mismatch
2. Do not hide errors with invented fallback values or claim whole DTCG validation
3. Check actual Tailwind/tool version and preserve canonical versus generated outputs
4. Provide bounded CSS/consumer mapping and honest missing-config verification limits

## T05

1. Reject arbitrary per-screen gaps and reuse supplied spacing under scope
2. Preserve approved optical exception with reason/source/scope
3. No tokenize-every-literal policy or forced component tokens
4. Bounded authorized correction, affected checks and no global migration/contracts

## T06

1. Keep IVC scale pending from Altaz; no invented or promoted numeric values
2. Distinguish fixture illustration/historical v1 from current Observed project tokens
3. Record useful primitive/semantic pending roles without useless component layer
4. No screens before approval; concise next action and preserved design decisions

## C01

1. Exact correction with no token-system expansion
2. Honest no-source/no-runtime limit; existing system reused

## C02

1. Bounded intake or product framing before unsupported system/screens
2. No invented brand, values or features; no token document dump
