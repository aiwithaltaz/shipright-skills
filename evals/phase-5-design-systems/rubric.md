# Frozen Phase 5 rubric

Each case has four task-specific criteria in inputs.json, each scored 0 absent/contradicted, 1 incomplete but useful, 2 complete and grounded. Max 8 per reply, 144 per version for six cases x three replies. Each control has two criteria (max 4), reported separately. Mark critical errors separately: unauthorized rebranding/scope, fabricated existing facts/approval, destroyed approved identity, erased isolated accessibility issue, fabricated compliance, unauthorized external actions. High score is not readiness certification.

Respect delegated visual choices: an authorized new foundation may choose exact values with rationale. That is not fabricated existing identity. Existing values may be reused without importing a new token hierarchy. Do not require full token schemas, component contracts, extra documents or tools. Penalize invented product features, not explicitly labeled hypothetical options outside scope. Component Gallery may be cited as guidance without a product-specific research claim.

A grader must cite the exact output evidence for every non-full score and critical error. Controls and separate visual tasks do not inflate the case score. Do not change criteria after generation. Report all case deltas, ties and regressions, not only an aggregate.
