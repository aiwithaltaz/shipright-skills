# Phase 3 IA evaluation protocol

Frozen before trial responses on 2026-10-11. Main baseline: 758702ad4b84841dee28b2ea1fc7684c5fa71d05. Six IA cases, three fresh isolated trials per version per case: 36 replies. Two separate controls, one fresh reply per version each: four replies. Same raw prompts and wrapper, no version labels, criteria, expected answers, prior replies or parent history. No model overrides; serving model/seed not exposed.

Trial directories contain only frozen skills, project templates, opt-in taste files and the raw task. No browsing, source edits, paid calls, app changes, messages or unrelated reads. Save exact answer and self-reported relative pack-file reads. Synthetic fixtures are not research. Preserve every run/failure; any operational replacement must be a separate record. Freeze updated sources before any trial; do not tune guidance or rubric after outputs.

After replies finish and hashes match, shuffle anonymous texts per case. Fresh graders receive only raw prompt, frozen rubric and anonymous answers, with no pack, versions, mapping or read lists. Retain first scores/reasons. Parent checks arithmetic/completeness; any factual adjudication remains separate and declares whether blinded. Unblind after all grading. Controls reported separately.

Run existing and new source/mutation, token, unittest and whitespace checks. Preserve historical artifacts and failures unchanged. No visual artifacts, merge or Phase 4. Report regressions, ties, limits and critical errors without claiming real usability, security verification, statistical superiority or cross-model reliability.
