# Altaz's design preferences

**Optional profile, updated October 4, 2026.** Apply only when selected.
Current instructions and the existing approved system take precedence. These preferences do not authorize product scope.

- Keep screens simple and organized. Useful information matters more than decoration or empty space.
- Keep branding restrained in work tools. Use supplied assets without displacing the task.
- Give each fact a useful home. Avoid duplicate account boxes, filler chips and repeated background facts.
- Keep the current task, blockers, amounts and consequences visible. Put occasional detail in accessible help.
- Use summaries to verify entered work, with existing permitted edit/resume routes.
- Keep actions, labels, icons, components and spacing consistent across the app.
- Prefer an even border around a selected list row over a heavy left accent. Preserve clear selection and focus cues.
- Show visible progress and a clear exit in multi-step work: where the user is, whose details are active, what remains, and how to leave without losing valid work.
- Use the supplied logo for the favicon, not an invented initial or generic icon.
- Build tables around what people compare. Put secondary facts next to their main item and deeper detail in the record view.
- Decide the primary action side once in the design system and use it the same way across the app.
- For a new layout without an existing system, prefer 8-point spacing: 4, 8, 12, 16, 24, 32 and 48. Preserve an approved system, including a 4px system.

A bottom-left profile home is specific to the registration desk correction, not every product.
No preference requires a sidebar, wizard, table, summary panel or new feature.
Eligibility, waivers, payments, fees, age rules and permissions remain product decisions.
