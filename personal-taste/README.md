# Optional taste profiles

A profile applies only when selected by the user or project instructions. A bundled author's name does not select it.
Keep that selection for the session/project; do not ask at each skill boundary.
Use [Altaz's profile](altaz.md) when requested. Missing profiles do not block work.
Current instructions and approved project values outrank preferences. Profiles cannot add features, facts or permissions.
Core scope, truthfulness and accessibility rules apply to all four skills.
